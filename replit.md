# FintechPressHub

## Overview

FintechPressHub is a professional digital marketing and content agency website specializing in the fintech sector. The project aims to provide a comprehensive online presence, showcasing services, expertise, and thought leadership through a blog. It integrates advanced SEO features, author management, content moderation, and robust administrative tools to streamline operations and enhance user experience. The platform is designed to attract, engage, and convert prospective clients in the competitive fintech market, with a strong emphasis on content quality, search engine visibility, and user engagement.

## System Architecture

**Frontend:** The frontend is built with React, Vite, Tailwind CSS, shadcn/ui for UI components, framer-motion for animations, and wouter for routing. It's structured as a single-page application (SPA) with server-side rendering (SSR) for initial page loads and SEO optimization. Key UI/UX decisions include a professional blue color palette (`hsl(var(--primary)) = #0052FF`), responsive design for all pages, and intuitive navigation.

**Backend:** The backend is an Express 5 API server handling various functionalities such as blog post management, service and pricing data, testimonials, contact forms, guest post submissions, and administrative tasks. The API is designed to be RESTful, with endpoints for content delivery and system management.

**Database:** PostgreSQL is used as the primary database, managed with Drizzle ORM. Database schemas are defined in `lib/db/src/schema`. The system includes an idempotent seeding mechanism for initial data population.

**API Contract:** OpenAPI specification (`lib/api-spec/openapi.yaml`) defines the API contract, enabling automatic generation of React Query hooks and Zod schemas for type safety and data validation across frontend and backend.

**Monorepo:** The project is structured as a pnpm monorepo using TypeScript 5.9 and Node 24, promoting code sharing and consistent development practices across frontend, backend, and shared libraries.

**SEO & Content Features:**
- **Dynamic Sitemap and RSS Feeds:** Sitemap (`/sitemap.xml`) and per-author RSS feeds (`/authors/:slug/rss.xml`) are dynamically generated by the API, ensuring up-to-date content for search engines and subscribers.
- **JSON-LD and Open Graph:** Extensive use of JSON-LD (`BlogPosting`, `Service`, `FAQPage`, `AboutPage`, `Organization`, `Person`) and article-flavored Open Graph tags for enhanced search engine visibility and social media sharing.
- **IndexNow Integration:** Automated IndexNow pings on content publication/update and a daily scheduled job to notify Bing, Yandex, Seznam, and Naver about new/updated blog posts. Admin UI provides status and re-ping functionality.
- **Prerendering for Crawlers:** A build-time prerendering script generates static HTML files for key routes, ensuring search engine crawlers receive fully rendered content without relying on client-side JavaScript execution.
- **Content Quality Bar:** Enforced post length (800-1500 words) and inclusion of inline imagery for improved readability and SEO.
- **Admin Author Selector:** Facilitates assigning blog posts to team members or guest authors, with author quota warnings to balance editorial load.
- **Commissioning Topics:** An admin-curated list of pitch topics displayed on the "Write For Us" page, with public visibility and admin management.
- **SEO Overrides:** Per-post SEO metadata overrides (title, description, OG image) for fine-grained control.
- **"Newly Published" Badge:** Highlights recent posts on the blog index page with a filter option.
- **Legal Page "Last Updated":** Automates "Last updated" timestamps for legal pages using git commit times.

**Admin & Moderation:**
- **Admin Authentication:** Protected admin routes using Replit OIDC with an email allowlist for authorization.
- **Sitemap Health Check:** Daily job and on-demand admin tool to check for broken links in the sitemap, with email and Slack notifications for persistent failures.
- **Bulk No-Index:** Admin functionality to no-index/re-index multiple posts with impact preview, audit logging, and snooze options for temporary removal from search.
- **Content Reports:** Public-facing form on blog posts for reporting content issues, feeding into an admin moderation queue with email alerts.
- **Author Headshot Management:** Admin UI for overriding author headshots, enforcing image dimensions, and a public submission queue for authors to propose new photos.

## External Dependencies

- **PostgreSQL:** Primary database for all application data.
- **Drizzle ORM:** TypeScript ORM for interacting with PostgreSQL.
- **Express:** Web application framework for the API server.
- **React:** Frontend JavaScript library for building user interfaces.
- **Vite:** Next-generation frontend tooling for fast development.
- **Tailwind CSS:** Utility-first CSS framework for styling.
- **shadcn/ui:** Reusable UI components.
- **framer-motion:** Animation library for React.
- **wouter:** A tiny routing library for React.
- **Nodemailer:** Library for sending emails (for contact forms and admin notifications).
- **Resend:** Email API for sending rich HTML reports.
- **Google Cloud Storage:** Object storage for cover image uploads.
- **IndexNow API:** For notifying search engines (Bing, Yandex, Seznam, Naver) about content changes.
- **Slack Incoming Webhooks:** For sending notifications to Slack channels.
- **Replit OIDC:** For user authentication and authorization in admin panels.
